# 脚本

脚本功能位于 **我的→设置→脚本**，通过在内置浏览器中注入 JavaScript 脚本，帮助用户自动化完成一些重复性操作。

> ⚠️ 脚本功能依赖内置浏览器的 JS 注入能力，使用前请确保已在对应网页中完成登录。

---

## 📖 WeLearn 刷题

### 使用方法

1. 打开中大儿，进入 **服务→脚本→WeLearn**，或在 **WeLearn 学习界面** 底部工具栏点击 **JS** 图标，选择「WeLearn助手」。
2. 进入 WeLearn 对应课程的答题页面。
3. 在网页界面中配置刷题选项（如答题速度、是否自动提交等）。
4. 点击开始，脚本将自动完成题目作答。

### 支持的题型

| 题型   | 支持情况 |
| ------ | -------- |
| 单选题 | ✅ 支持  |
| 多选题 | ✅ 支持  |
| 填空题 | ✅ 支持  |

> 💡 该脚本能完成大部分题目，效果以实际为准。建议使用后检查答题结果。

## 中大儿增强脚本

> 该脚本同时在支持脚本的浏览器中运行，使用方法参考[sysuer-script](https://github.com/SYSU-Tang/sysuer-script)。

### ⚙️ 可视化配置面板

- **便捷入口**：页面右下角常驻悬浮按钮（⚙️），也可通过油猴扩展菜单呼出，随时随地修改配置。
- **中大专属主题**：UI 深度定制，面板与提示框均采用中山大学标志性**“中大绿”（`#005826`）**配色，沉浸感十足。
- **即时生效**：所有配置项（如账号密码、功能开关）均可通过图形化面板修改，持久化保存在本地。

### 🚀 自动化登录与网络优化

- **自动登录 NetID**：在 CAS 统一身份认证页面自动填写账号密码并提交。
- **绕过 二次 验证**：自动注入信任 Cookie，跳过繁琐的多因素认证页面。
- **智能 WebVPN 跳转**：在外网访问受限的校内资源（如 `appgw` 或 `visitor` 拦截页）时，自动替换域名跳转至 WebVPN。
- **无缝中转**：在教务系统、LMS、Portal 等系统的中转页，自动点击“登录”按钮，减少鼠标点击次数。

### 🎓 页面净化与美化

- **去除冗余元素**：精简教务系统（jwxt）及官网中无用的头部、底部、面包屑导航和调查问卷。
- **排版优化**：自动拓宽成绩查询、个人培养方案等页面的表格展示区域，提升信息获取效率。

### ⏩ 在线教学平台视频速通

- **视频速通**：检测到在线教学平台（`lms.sysu.edu.cn`）的视频任务时，自动高频提交视频播放进度，数秒内完成观看视频任务。
- **自动连播**：视频进度提交完成后，自动点击“下一页”进入下一个学习任务。

### 🎉 等级制显示原始分

- **原始分显示**：在成绩查询页面，点击`原始分`按钮，即可查看每个课程的原始分。
